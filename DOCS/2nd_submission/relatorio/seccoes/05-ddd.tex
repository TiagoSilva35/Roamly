\section{\textit{Domain-Driven Design}}\label{sec:ddd}

De forma a criar um \textit{Domain model}, foi preciso primeiro definir um glossário de termos para cada domínio.
Este modelo mostra os vários conceitos que as palavras no glossário representam no nosso sistema.
As setas e os traços representam as relações entre estes conceitos.
As setas roxas conectam conceitos de diferentes contextos, enquanto os traços a preto representam as relações entre conceitos (associação ou herança).
